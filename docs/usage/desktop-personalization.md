# 桌面个性化：宠物、背景与外观设置

## 概览

`go-e2e` 的 Desktop/WebUI 不只是一个聊天窗口，还提供了一个可持续运行 Agent 任务的个性化工作台。当前的“皮肤”能力主要由两部分组成：**内置桌面陪伴角色**和**背景/视觉外观设置**。

当前版本不是皮肤商城，也不承诺任意上传 3D 角色；内置角色资源通过可扩展的资产注册表管理，现有角色包括 **Go 伙伴** 和 **中国龙**。

## 如何打开设置

在 Desktop 或 WebUI 中打开设置中心：

- `设置 → 宠物`：选择、显示和调整桌面陪伴角色。
- `设置 → 外观`：调整背景、透明度和内容层模糊效果。

保存后，设置会经过校验和读回确认；CLI/TUI 不依赖这些视觉能力，可以在没有桌面宠物的情况下完整运行 Agent。

## 桌面陪伴角色

### Go 伙伴与中国龙

当前内置两种角色：

| 角色 | 适合的表达 |
| --- | --- |
| **Go 伙伴** | 默认、轻量、适合日常编码工作台 |
| **中国龙** | 更有辨识度的桌面陪伴形象 |

角色可以在设置预览中切换；桌面上的角色也可以直接拖动到合适的位置。

### 动画、大小与位置

`设置 → 宠物` 支持：

- 启用/禁用桌面宠物，以及显示/隐藏角色。
- 切换 `待机`、`专注`、`庆祝` 动画状态。
- 调整角色缩放、默认右侧距离和底部距离。
- 开关状态气泡，并调整气泡文字缩放。
- 在当前设备关闭宠物，之后可以从宠物设置中恢复显示。

这些设置用于个性化工作台，不改变 Agent 的 Runtime、模型请求或任务执行逻辑。

## 背景设置

### 背景颜色与图片 URL

`设置 → 外观` 支持设置：

- 背景颜色。
- 背景图片 URL：适合使用可访问的 `https://` 图片地址或项目内资源路径。
- 背景遮罩透明度，让背景与文本可读性保持平衡。

### Desktop 本地背景上传

Desktop 额外支持从本地选择背景图片。支持格式：

- PNG
- JPEG/JPG
- WebP
- GIF

选择后可以替换或移除当前本地背景。应用会校验图片格式、尺寸和大小，避免把无效或过大的文件写入桌面数据目录。

## 视觉外观控制

除了背景本身，还可以在 `设置 → 外观` 调整以下内容层：

- **侧栏表面色透明度**：控制会话列表侧栏的透出程度。
- **气泡不透明度**：控制消息或状态气泡的视觉重量。
- **空状态模糊**：调整没有打开会话时的背景层模糊。
- **对话模糊**：调整对话内容区域的背景层模糊。
- **编辑区模糊**：调整消息输入区的背景层模糊。

模糊只作用于对应内容层，不会把整个页面统一处理成不可读的滤镜。

## 数据与隐私

- Desktop 本地上传的背景会保存到桌面端本地数据目录，默认位于 `~/.golang-cc/` 下的受管控资源目录。
- 本地背景不会作为模型请求内容发送给你配置的 Provider。
- 背景图片 URL 仍然是外部资源地址；请根据自己的网络、版权和隐私要求选择地址。
- 设置文件、SQLite、日志和本地背景都属于本机数据，不要把包含个人信息或真实业务内容的文件提交到 Git。

## 当前边界与后续扩展

- 当前公开支持的是 Go 伙伴和中国龙，不是完整的皮肤市场。
- 当前不宣传任意用户上传 3D 角色或在线角色商城。
- 角色资产通过注册表接入，后续可以在保持设置接口稳定的前提下增加更多角色、海报和动画资源。
- CLI/TUI 是终端入口，不依赖宠物、背景和模糊等桌面视觉能力。

## 常见问题

### 宠物会影响模型能力或任务执行吗？

不会。宠物是前端视觉层，只影响显示、位置、动画和状态气泡，不改变 Runtime、Provider、工具权限或任务执行。

### 我可以上传自己的背景吗？

Desktop 可以上传 PNG、JPEG/JPG、WebP 或 GIF 图片，也可以替换和移除本地背景。WebUI 可以使用背景颜色和图片 URL；本地文件上传能力以 Desktop 为准。

### 可以添加更多角色吗？

架构上可以。当前内置角色是 Go 伙伴和中国龙，更多角色需要以项目资源和代码形式加入；目前没有任意 3D 角色上传入口。
