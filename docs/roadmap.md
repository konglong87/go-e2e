# Roadmap

这是公开的方向说明，不是对具体日期和功能的承诺。优先级会根据真实用户反馈、Issue、Discussion 和维护成本调整。

## 当前重点

- 让 Desktop、CLI、TUI 和 WebUI 的首次运行路径更清晰；
- 持续完善跨平台 Release、校验和安装验证；
- 补充 Provider、MCP、Skills 和典型 Coding Agent 任务示例；
- 提升长任务、会话恢复、权限边界和结果验证的可靠性；
- 降低文档、示例、测试和 Provider 适配的首次贡献门槛。

## 适合外部贡献的方向

- 完善英文文档和平台安装说明；
- 增加一个脱敏的使用场景或录屏；
- 补充兼容 API、模型和 MCP server 的配置示例；
- 为已有能力补充聚焦测试和真实验收步骤；
- 报告跨平台安装、Provider 兼容性和文档断链问题。

## 如何影响路线图

优先提交带有最小复现、用户价值、影响范围和验证方法的 Issue。需求讨论请使用 GitHub Discussions，明确缺陷请使用 Issues，代码实现请通过 PR 提交。
