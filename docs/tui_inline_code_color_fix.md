# TUI Inline Code 颜色过亮 — 修复方案

## 问题

TUI 模式下，Markdown 中的 inline code（反引号包裹的代码片段）颜色过亮，与正文对比过于刺眼。

## 当前值

`app.go:3585-3586`：

```go
inlineCodeColor := "209"       // 256色表中的亮橙/珊瑚色 (≈ #ff875f)
inlineCodeBackground := "236"   // 256色表中的深灰 (≈ #303030)
```

正文颜色为 `"253"`（≈ #dadada，浅灰白）。

**问题分析**：256 色表中 209 是高饱和度的亮橙/珊瑚色，在深色背景（236）上非常刺眼，与正文（253 浅灰白）的柔和风格形成强烈反差。inline code 应该是**微妙区分**正文，而不是**抢夺注意力**。

## 修复方案

将 `inlineCodeColor` 从 `"209"`（亮橙）改为 `"180"`（柔和淡紫/薰衣草色）。

```go
// 修改前
inlineCodeColor := "209"

// 修改后
inlineCodeColor := "180"
```

### 颜色对比

| 元素 | 当前值 | 修改后 | 256色表色值 | 视觉效果 |
|------|--------|--------|-------------|----------|
| 正文 | `"253"` | `"253"` | ≈ #dadada 浅灰白 | 不变 |
| inline code 前景 | `"209"` | `"180"` | 209≈亮橙 → 180≈淡紫 | 从刺眼变为柔和区分 |
| inline code 背景 | `"236"` | `"236"` | ≈ #303030 深灰 | 不变 |
| code block 前景 | `"253"` | `"253"` | ≈ #dadada | 不变 |
| code block 背景 | `"235"` | `"235"` | ≈ #262626 | 不变 |

### 为什么选 `"180"`

- 256 色表中 180 是柔和的淡紫/薰衣草色（≈ #d7afd7），饱和度低，亮度与正文（253）接近
- 在深灰背景（236）上清晰可辨但不刺眼
- 与项目已有的 accent 色 `"42"`（绿色）和 link 色 `"45"`（蓝色）形成互补但不冲突
- 与 code block 前景色 `"253"` 有足够区分度（inline code 有背景色 + 不同前景色，code block 只有不同背景色）

### 其他候选值

| 值 | 色值 | 评价 |
|----|------|------|
| `"180"` | ≈ #d7afd7 淡紫 | **推荐**：柔和、与正文亮度接近、辨识度够 |
| `"174"` | ≈ #d78787 暗粉 | 偏暖，辨识度好但略偏红 |
| `"183"` | ≈ #d7d7af 暗米黄 | 偏暖黄，辨识度稍弱 |
| `"251"` | ≈ #c6c6c6 浅灰 | 太接近正文，区分度不够 |
