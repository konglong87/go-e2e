## Hacker News body

```text
I built go-e2e, an open-source coding agent written in Go. It is local-first and exposes the same runtime through Desktop, CLI, TUI, and WebUI.

The goal is task execution rather than chat-only responses: inspect a repository, plan the work, use tools, edit files, run commands, and report verification results.

Current extension points include custom model Providers, MCP, Skills, Profiles, permissions, sessions, memory, and multi-agent workflows. SQLite is the default local store; MySQL is available for private/team deployment.

The v0.3.4 release includes macOS arm64/amd64 DMGs, a Windows installer, Linux desktop artifacts, CLI archives, and SHA256SUMS:
https://github.com/konglong87/go-e2e/releases/tag/v0.3.4

Quick start:
  git clone https://github.com/konglong87/go-e2e.git
  cd go-e2e
  go run ./cmd/go-e2e --version

You still need to configure a model Provider and API credentials. The project is in 0.x, and I am explicitly looking for feedback on first-run friction, Provider compatibility, MCP examples, and cross-platform installation.

What would you try first, and what would make this useful enough to keep installed?
```

## Reddit: r/selfhosted / r/LocalLLaMA angle

```text
go-e2e is an open-source, local-first coding agent written in Go. It can run from Desktop, CLI, TUI, or WebUI, uses SQLite locally by default, and connects to custom or OpenAI-compatible model Providers.

It supports MCP and Skills for extensions, but it does not bundle a model or hide the data boundary: model requests go to the Provider you configure.

Release: https://github.com/konglong87/go-e2e/releases/tag/v0.3.4
First-run guide: https://github.com/konglong87/go-e2e/blob/main/docs/getting-started.md

The project is 0.x. I am looking for real installation and first-task feedback rather than drive-by stars: platform, model protocol, time to first successful task, and the first confusing step are all useful.
```
