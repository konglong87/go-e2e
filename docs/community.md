# 社区与贡献入口

欢迎使用、提问、反馈和贡献 go-e2e。为了让问题更容易被处理，请选择最合适的入口。

| 事情 | 入口 |
| --- | --- |
| 版本公告和重大变更 | [GitHub Releases](https://github.com/konglong87/go-e2e/releases) |
| 使用问题和方案讨论 | [GitHub Discussions](https://github.com/konglong87/go-e2e/discussions) |
| 可复现 Bug | [GitHub Issues](https://github.com/konglong87/go-e2e/issues) |
| 功能建议和路线图 | [Ideas Discussions](https://github.com/konglong87/go-e2e/discussions/categories/ideas) |
| 安全漏洞 | [SECURITY.md](../SECURITY.md)；不要公开提交敏感细节 |
| 中文即时交流 | [飞书社群](https://applink.feishu.cn/client/chat/chatter/add_by_link?link_token=55aq8d1d-7586-46cf-8635-a8c321ad284d) |
| 代码、文档和示例 PR | [CONTRIBUTING.md](../CONTRIBUTING.md) |

## 提交问题时请提供

- go-e2e 版本或 commit；
- 操作系统、架构和使用入口；
- Provider、协议和模型类型（不要贴 API Key）；
- 最小复现步骤；
- 实际结果、期望结果和相关日志；
- 如果是 UI 或安装问题，附上脱敏截图和完整错误文本。

## 第一次贡献从哪里开始？

优先查看带有 `good first issue`、`help wanted`、`documentation` 和 `provider` 标签的 Issue。
文档、示例、测试和跨平台验证同样是高价值贡献，不需要先修改 Runtime Core。
