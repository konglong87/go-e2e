The WebUI has not been built yet

The server is running and its HTTP API is healthy — only the browser frontend is missing. The frontend is a Vite bundle that is compiled from source rather than shipped inside this binary, so it has to be built once before /webui/ can serve anything.

Build it

From the repository root, using Node 20.19+ or 22.12+:

npm --prefix web ci --legacy-peer-deps
npm --prefix web run build

--legacy-peer-deps is required: typescript@6 and openapi-typescript@7 declare a known, harmless peer conflict.

Then reload this page. If you started the server from the repository root, the freshly built web/dist is picked up automatically — no environment variable needed.

Or point the server at an existing build

If you build elsewhere, or run the server from another directory, set the directory explicitly and restart: 

GOLANG_CC_WEBUI_DIR=/path/to/web/dist golang-cc server

The directory must be the build output itself — the one that contains index.html.

Meanwhile, these work right now

Both are served straight from this binary and need no build step:

  • /trace — session, span, and tool-call trace viewer
  • /prompt-dump — captured prompt inspector

Serving this page instead of a bare 404 is deliberate: a 404 here is indistinguishable from a build that has no web UI at all.
